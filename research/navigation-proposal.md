# 읽기 구조 개선 제안

2026-09-24 · 현재 소스와 생성 페이지 기준. 사용성·정보 위계·일관성·접근성 관점의 검토이며, 사용자 테스트를 실시한 결과는 아닙니다.

## 권고: 목차형 홈 + 장별 읽기 + 독립 실험실

기존 14개 장의 독립 정적 URL을 기본 읽기 경로로 사용하고, 긴 전체 책은 선택 기능으로 남기는 방식을 권합니다. SPA나 서버 전환 없이 현재 Python → 정적 HTML → 공개 GitHub Pages 구조를 유지할 수 있습니다.

```text
홈: 책 소개 · 14장 목차 · 목적별 학습 경로 · 이어 읽기
 ├─ 장별 읽기: 해당 장만 표시 · 소목차 · 이전/다음 장
 │   └─ 관련 실험: 질문 → 조작 → 비교 → 설명 → 장으로 돌아가기
 ├─ 실험실: 질문별 실험 목록 · 관련 장 · 이전/다음 실험
 └─ 전체 책 / 용어집 / 참고문헌 / 보존 PDF
```

## 최초 검토에서 관찰한 문제

| 관찰 | 영향 | 우선 개선 |
|---|---|---|
| 기본 홈에서 모든 장을 한 번에 읽는 형식 | 새 방문자는 전체 분량·학습 순서와 다음 행동을 파악하기 어려움 | 첫 화면을 책 소개와 장별 목차로 전환 |
| 장별 URL은 이미 있으나 기본 탐색은 전체 책의 앵커 중심 | 특정 개념을 읽다가 긴 페이지로 되돌아갈 수 있음 | 장 링크를 장별 URL로 통일; 장 내부 소제목만 앵커 사용 |
| 장의 내용·실험 밀도에 큰 차이가 있음 | 긴 장에서는 현재 위치를 잃기 쉬움 | 장별 소목차, 현재 절 표시, 장 끝의 다음 장 버튼 |
| 모바일에서 실험과 조작부가 세로로 길게 놓임 | 변수 변경 뒤 결과를 찾기 위해 왕복 스크롤이 발생 | 핵심 변수 우선 배치, 심화 변수 접기, 화면 높이까지 고려한 결과 배치 |
| 기존 책은 여러 언어가 부분 번역임 | 같은 언어 선택이 모든 내용의 번역 완성을 뜻하는 것으로 오해될 수 있음 | 번역 범위 안내, 영어 대체 링크 명시 |

중성 배경, 색 패치와 설명의 병치, 기존 장별 주소와 공유 기능은 유지할 가치가 있습니다. 새 탐색 UI가 색 실험보다 시각적으로 강해지지 않도록 해야 합니다.

## 구조 대안 비교

| 안 | 장점 | 한계 | 판단 |
|---|---|---|---|
| 긴 페이지 + 접기/펼치기 | 변경량이 작음 | 공유·뒤로가기·현재 위치 문제는 남음; 본문이 숨겨짐 | 임시 완화 |
| **목차형 홈 + 장별 정적 페이지 + 실험실** | 분량·목표가 명확함; 주소 공유·접근성·정적 배포에 적합 | 홈·탐색 링크 정비 필요 | **권고** |
| 앱형 SPA / 탭 전환 | 복잡한 학습 상태 관리에 유리 | JS 의존성과 라우팅·접근성 부담; 현재 목표에는 과함 | 보류 |

## 구체적인 화면 구성

### 홈

- 간단한 소개와 두 진입 버튼: `처음부터 읽기` / `실험으로 배우기`.
- 14개 장을 4개 묶음으로 표시: 기초(1–3), 색을 다루는 언어(4–7), 지각과 활용(8–10), 문화·재료·제작(11–14). 이는 탐색용 묶음이며 장 번호는 유지합니다.
- 목적별 경로: 처음 배우기 / 디자인·웹 / 회화·사진·인쇄 / 역사·자연.
- 읽기 시간은 실제 본문 길이에 근거해 산정할 때만 표시합니다.

### 장별 읽기

- 데스크톱: 왼쪽 장 목차, 가운데 본문, 긴 장에 한해 오른쪽 소목차. 모든 창에서 3열을 강제하지 않습니다.
- 태블릿·모바일: 접을 수 있는 장/절 목차와 현재 위치. 하단에는 큰 `이전 장` / `다음 장` 버튼을 두되 콘텐츠를 가리지 않습니다.
- 장의 순서: 학습 질문 → 짧은 핵심 설명 → 관련 실험 → 정리 → 다음 장.
- 용어 설명은 본문을 떠나지 않고 열 수 있게 하되, 용어집의 독립 URL도 유지합니다.
- 이어 읽기는 선택적으로 localStorage에 언어·장·절만 저장하며 계정·서버·추적 분석을 요구하지 않습니다. 실험 수치나 완료 이력을 꼭 저장할 필요는 없습니다.

### 실험실

- 한 페이지에 하나의 질문과 실험. 관련 장, 이전/다음 실험, 언어 전환 제공.
- 수치·곡선·텍스트를 함께 제공하고 색만으로 정답·경고를 표현하지 않습니다.
- 심화 변수 접기와 모바일 결과 고정은 실험별 검증 후 적용합니다. 화면 높이를 과도하게 차지하는 고정 패널은 피합니다.

## 이번에 구현한 범위와 다음 단계

**구현:** 독립 실험실 홈, 8개 실험 × 한글/영문 페이지, 기존 관련 장의 실험 링크, 실험별 앞/뒤 이동·관련 장 복귀·언어 전환·키보드 조작·초기화. 새 이론은 기존 전체 책에 긴 섹션으로 붙이지 않았습니다.

**추가 구현 — 사용자 선택 2·4번:** 기존 표지를 유지하면서 `장별로 읽기`와 `전체 이어 읽기` 선택을 제공합니다. 14개 장은 해당 장만 표시하며 상단에 접을 수 있는 장 이동·소목차와 현재 절 표시, 하단에 이전·다음 장 링크를 제공합니다. 14장 다음은 전체 판본의 연대기·팔레트로 연결됩니다. 전체 판본은 `/book/` 및 각 언어의 `/{lang}/book/`에 있으며, 읽는 중인 장의 독립 페이지로 돌아갈 수 있습니다. 언어 전환은 읽기 방식과 앵커를 유지합니다.

기존 루트의 `#장`, `#실험`, `#chronology`, `#coda` 주소는 표지의 호환 스크립트가 새 주소로 연결합니다. 새 페이지의 소목차·장 이동은 일반 링크와 네이티브 details로 구성해 JavaScript 없이도 이용할 수 있습니다. 모바일에서는 목차 패널을 화면 폭 안에 배치하고 접거나 Escape로 닫을 수 있게 했습니다.

**제안 상태:** 목차형 홈, 읽던 위치 자동 저장, 실험별 모바일 조작부 재배치. 이번 선택에 포함되지 않은 홈 전면 개편이나 계정·학습 진도 기능은 구현하지 않았습니다. 데스크톱 3열 고정 레이아웃 대신 작은 접이식 탐색 막대를 채택해 기존 본문·실험의 폭을 유지했습니다.

이후 확장한다면 목차형 홈, 실험별 모바일 조작 흐름, 선택적인 읽던 위치 저장을 별도로 검토할 수 있습니다. 현재 구현은 서버나 SPA 라우터 없이 생성된 정적 HTML로 동작합니다.

## 완료 판정

1. 홈에서 원하는 장 또는 실험까지 두 번 이하의 링크 선택으로 도달합니다.
2. 새로고침·직접 주소 접속·브라우저 뒤로가기로 같은 장이 유지됩니다.
3. 언어를 바꿔도 대응 장/실험이 유지됩니다.
4. 390px 모바일과 키보드만으로 목차·조작·초기화·다음 장 이동이 가능하며 가로 스크롤과 가려진 초점이 없습니다.
5. 실험은 서버 호출 없이 계산되고, JS가 꺼져도 이론·출처·탐색은 읽을 수 있습니다.
6. 기존 장·전체 책·PDF 주소, canonical, hreflang, sitemap의 회귀 검사를 통과합니다.
