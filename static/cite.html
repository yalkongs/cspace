How to cite

Citation formats for the whole book or any single chapter. Pick the part you cited, then copy the format your style guide asks for.

The Book of Color is an evolving online essay; if you cite it in scholarly or educational work, please include the exact URL you read and the access date so future readers can locate the same version.
